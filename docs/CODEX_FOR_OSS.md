# Codex For OSS Application Draft

## What project are you maintaining?

I maintain OpenInfraHub, a self-hosted infrastructure command center for homelabs, small teams, technicians, and MSP-style environments. It helps users organize node inventory, service monitoring, Proxmox/LXC visibility, Tailscale-aware fleet tracking, topology mapping, storage telemetry, alerts, and mobile-first infrastructure checks in one place.

## Why does this project matter?

Many self-hosters, technicians, and small businesses run real infrastructure without enterprise budgets. They still need to know what is online, what is degraded, where services live, and how their network fits together. OpenInfraHub gives them a practical, self-hosted operations view without requiring expensive monitoring platforms.

## How do you use Codex/OpenAI tools?

I am self-taught and use AI coding tools to accelerate development, documentation, security review, test planning, and refactoring. I use Codex/OpenAI tools to turn working private infrastructure ideas into safer, cleaner, reusable open-source code. I manually review changes and use AI assistance to improve docs, scan for sensitive information, write install steps, and build tests.

## What would better access help you build?

Better access would help me move faster on the parts that make this useful to the public: a clean Docker install, sample data, Proxmox and Tailscale integrations, monitoring adapters, a mobile-first dashboard, tests, security checks, redacted demo screenshots, and contributor-friendly documentation. I currently rely on limited paid AI coding access, and more access would directly improve the quality and speed of the public release.

## What is the public benefit?

OpenInfraHub helps homelab users, technicians, small businesses, and self-hosters manage infrastructure more safely and clearly. It gives people a practical starting point for inventory, monitoring, topology, and alerting without exposing private data or requiring enterprise tools.

## Why should this qualify?

This is a real project based on a real deployed infrastructure console. I am turning private infrastructure tooling into a clean public OSS project with security-first release practices. I have limited funds, I am self-taught, and I use AI tools to accelerate development responsibly. Better access would help me document, test, sanitize, and build the project into something useful for the broader self-hosting and small-operations community.
