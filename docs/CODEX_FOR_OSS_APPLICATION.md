# Codex For Open Source Application Packet

Use this as a draft when submitting the Codex for Open Source form:

https://openai.com/form/codex-for-oss/

The form is for maintainers of active open-source projects. OpenAI says it looks for projects with meaningful usage, broad adoption, or clear importance to the software ecosystem, and it reviews applications on a rolling basis.

## What You Still Need To Enter Yourself

- First name
- Last name
- Email associated with your ChatGPT account
- GitHub username
- Public GitHub repository URL
- Primary maintainer or core maintainer
- OpenAI Organization ID

## Suggested Form Answers

### What project are you maintaining?

OpenInfraHub, a self-hosted infrastructure command center for homelabs, small teams, technicians, and MSP-style environments. It provides a public-safe way to model node inventory, service monitoring, Proxmox/LXC visibility, Tailscale-aware fleet tracking, topology mapping, storage telemetry, alerts, and mobile-first operations views.

### Why does this project matter?

Many homelab users, technicians, and small businesses run real infrastructure without enterprise budgets. They still need a practical way to understand what is online, what is degraded, where services live, and how the network fits together. OpenInfraHub gives them a self-hosted operations layer without exposing private deployment data.

### How do you use Codex/OpenAI tools?

I am self-taught and use AI coding tools to accelerate development, documentation, security review, test planning, and refactoring. I use Codex/OpenAI tools to turn private infrastructure ideas into safer, cleaner, reusable open-source code, and I manually review all changes before publishing them.

### What would better access help you build?

Better access would help me move faster on the parts that make this useful to the public: a clean Docker install, sample data, Proxmox and Tailscale integrations, monitoring adapters, a mobile-first dashboard, tests, security checks, redacted demo screenshots, and contributor-friendly documentation.

### What is the public benefit?

OpenInfraHub helps homelab users, technicians, small businesses, and self-hosters manage infrastructure more safely and clearly. It gives people a practical starting point for inventory, monitoring, topology, and alerting without exposing private data or requiring enterprise tools.

### Why should this qualify?

This is a real project based on a real private infrastructure console that I have turned into a public OSS repository with security-first release practices. I am self-taught, I have limited funds, and I use AI tools to accelerate maintenance responsibly. The project is already public, has a sanitized demo, screenshots, schema, security scanning, and a roadmap that makes it useful to a broader self-hosting and small-operations community.

### If the form asks how you will use API credits

Use API credits for maintainer automation, docs generation, test scaffolding, release workflows, adapter development, and security review support for OpenInfraHub.

### If the form asks whether you are the primary maintainer

If you are the one actively stewarding the public repo, select primary maintainer. If another person shares the main maintenance burden, select core maintainer.

## Submission Checklist

1. Make sure your GitHub profile is public.
2. Make sure the OpenInfraHub repository is public.
3. Copy the repository URL from GitHub.
4. Fill in the maintainer role accurately.
5. Paste the drafted responses above into the relevant form fields.
6. Submit and keep an eye on the email tied to your ChatGPT account.

## What OpenAI Says It Will Review

- Whether the repository is public.
- Whether the project is actively maintained.
- Whether the project has meaningful usage, broad adoption, or clear ecosystem importance.
- Whether the applicant has ongoing maintainer responsibilities.
- Whether the repository and answers show a legitimate open-source maintenance workflow.

## Notes

- The form says selected maintainers may receive six months of ChatGPT Pro, conditional access to Codex Security, and API credits for coding and maintainer work.
- Applications are reviewed on a rolling basis, and selected applicants are notified by email.
